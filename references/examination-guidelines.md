# 《专利审查指南》怎么用

申请前工作流按相关行为及程序时点适用的现行法律、实施细则和《专利审查指南》核对。本地 2023 年版 PDF 是定位底本，不是已合并后续修改的现行全文。本文件维护版本、抽取入口和两类「技术问题」的区分；评述、权要和说明书仍用各节点工作流，不要把整本指南读进上下文。

底本：[工作区 `_shared/专利审查指南.pdf`](../../_shared/专利审查指南.pdf)。未修改条文可从该 PDF 核引，已修改条文以官方生效文本为准。不要用 `_shared/专利审查指南/md-parts/` 的 AnyDoc 合订本当条文：双栏和页眉被收成表，句子会切错。

## 版本与法源

截至 2026-09-21 本轮核验，已确认[国家知识产权局第 84 号令](https://www.cnipa.gov.cn/art/2025/11/13/art_74_202560.html)于 2025-11-10 公布，自 2026-01-01 施行。它修改了第二部分第四章第 6.4 节、人工智能相关审查规则等内容。以后首次处理实质法律判断、案件时点变化或有更新线索时，核对国家知识产权局是否有进一步生效修改，记录适用版本与条款；同轮已核适用条文无需重复联网。

2026 年起适用的 Ⅱ.Ⅳ-6.4 强调针对权利要求限定的整体方案评价创造性。用于支撑创造性贡献的特征应写入被评价的权利要求；只在说明书或下位从属项出现的特征不能补足上位独权。对解决技术问题没有贡献的附加特征通常不能带来创造性。具体原文和适用范围以第 84 号令为准。

涉及提交后修改边界时，核对[专利法第三十三条](https://www.cnipa.gov.cn/art/2020/11/23/art_97_155167.html)及[实施细则第五十七条](https://www.cnipa.gov.cn/art/2023/12/21/art_98_189197.html)：原始公开范围与修改时机、针对通知书缺陷修改是不同约束，不把最初独权等同于全部原始公开。涉及主动修改、答复、复审或无效的具体可接受方式时，再读对应程序章节；本技能不据此承接审查意见答复。

## 按节点抽哪一章

下表仅对应本地 2023 年底本，印刷页 +4 约为 PDF 页；后续修改按官方章节号定位，不套用旧 PDF 页码。它不是每次修改的必读清单。首次完整起草或全面审查按对应章核对；局部修改仅抽相关节及必要上下文，复用本轮已核过且适用的条文。纯错字或编号修改不重新抽整章。

## 怎么抽

可抽字的指南 PDF：用 `pypdf` 按页抽，汉字是连在一起的，便于 `rg`。本机若用 `pdftotext -enc UTF-8 -layout`，须先去掉汉字之间的空格，否则 `rg 技术问题` 会漏命中。

不要对原 PDF 整本 AnyDoc，也不要 `--ocr hosted`。化学通式图和索引会触发 AnyDoc `--ocr reject`；通式本身仍以看 PDF 为准。

```powershell
python -X utf8 -c "from pypdf import PdfReader; r=PdfReader(r'C:\Users\Administrator\Desktop\专利\_shared\专利审查指南.pdf');
for i in range(147,170):
    t=r.pages[i].extract_text() or ''; print('===== PDF', i+1, '====='); print(t)"
```

上例用于完整核对第二章；局部任务按上表缩小页码。抽完用 `rg` 节号，例如 `2.2.4`、`3.2.1.1`、`3.2.1`。扫描件或抽不出字的页：暂停依赖该页的判断，不要整本 OCR。

## 两类技术问题

说明书发明内容里的「要解决的技术问题」是 Ⅱ.Ⅱ-2.2.4：现有技术中存在的缺口，用正面、简洁的话写，可以带效果，不得写成广告，也不得把本案手段写进去。

评述第三节「实际解决的技术问题」是 Ⅱ.Ⅳ-3.2.1.1：相对最接近现有技术，由区别特征在本发明中的效果反推的改进任务。审查员重新确定的问题可以不同于说明书原句。问题不得写成区别特征本身，也不得包含对手段的指引或暗示。效果与最接近技术都相当时，只能写成提供另一种可选方案。

申请前对齐口径，不要追求两段话字面相同：

- 评述第三节用 3.2.1.1 的客观问题，不写本案组分、涂层构成或「提供一种……聚合物」。
- 说明书背景末句与评述第三节的技术口径和证据状态衔接，不要求复制原句。
- 发明内容按 2.2.4 分问题、方案、效果。问题与第三节同一缺口；方案才写聚合物、隔膜、制备方法。不要用「本发明要解决的技术问题是：提供一种……使……共同构成……」去对齐评述。
- 有益效果用评述第二节。化学领域多数情况要用实验数据，不得只断言。

「结合启示」「本领域技术人员有动机」只写在评述里，不写进说明书背景。
