# 创造性检索分析

本文是案件目录中创造性评述的正文骨架。填写时直接使用下列一至五节标题和固定句式，不要改成 0～13 节，不要使用表格。检索式、交底拆分、特征对照、待下载清单写入工作底稿或对话，不写入本评述。

填写规则：

- 区别有几项写几项。一项就写一项，够的可以续写 2、3……。不要为了配文件数量而拆区别，也不要把用途、黏度、基材、涂布窗口升成独立编号，除非有单独对照证明它产生了可测效果。
- 评述正文通常写入 1 件最接近文件，另加 1～2 件真正能补区别或构成结合风险的辅助文件，合计约 3 件。检索可以更宽；背景、同族和误命中留底稿。不要因为检索到很多就全部写入，也不要为凑三件而把背景文件写成对比文件。只有一项区别、且只需一件辅助文件就能评完结合风险时，可以只写对比文件1和对比文件2。
- 辅助文件按其实际公开的内容评述它碰到的那些区别。一件文件可以评多项区别，一项区别也可以没有任何辅助文件覆盖。禁止「对比文件2必须对区别1、对比文件3必须对区别2」。
- 效果、客观问题和意外效果按对照实验已经成立的口径写。数据尚未到位时，只在文首用一两句话标明「以下为实验成立后的撰写口径」，不要把未测结果写成已经完成的事实。
- 有创造性与无创造性只选一种口径，不要混写。不要写「审查员会说」。技术问题中不要直接写入本案技术方案。未证实的键合、网络、协同和未测性能不得当作区别技术特征或已证明效果。
- 新颖性与创造性分开：单件文件评新颖性，结合评创造性。
