# 实验设计

由 `SKILL.md` 进入本节点后再读本文件。写之前先读本案 `创造性检索分析.md` 和 `权利要求书.md`。用户只要解释时，默认不改文件。不编测定数字。

本节点的交付物是案件根目录 `实验设计.md`：给甲方审阅、给研发按表实施，不写入申请文本。xlsx 可给研发填数，对照关系以 `实验设计.md` 为准，不要两套表各写各的。分组和对照不要抄进 `workbench/05_说明书支撑与实施例计划.md`。

## 和前后节点

评述列出缺哪些对照，权要给出实施例必须落入的方案。对比例优先排评述要的对照；实施例优先让权要区间有落点。组数对称是观感，不能倒过来指挥设计。

表锁定后，说明书具体实施方式的组编号和中心组配方跟表。未锁定时说明书不要把组数写死。改表后核说明书是否仍对齐；用户未要求改说明书，只指出不一致，不要擅自改说明书。

## 怎么分组

1. 中心组是当前拟保护的完整方案，编号为实施例1。对比例的对应用量与它对齐。
2. 实施例落在拟保护方案内。对比例只用于：缺必要组分、最接近文件那条路、已经写入权要的范围外。交底里的模型窗口若未写入权要，窗口外仍可叫对比例，不要写成「不是本发明」。
3. 一组对照只动一个因素。评述要的对照优先于把实施例和对比例凑成相同数量。多出来的实施例用来补权要区间或第二个独立变量，不要在已有梯度上插点凑数。
4. 同一轮不要同时改材料种类、粒径、基材和施加方式，除非用户要求。

## 案件文件

`实验设计.md` 只保留固定条件、一张表、表下的成对对照句。测定细则写在说明书表征方法，这里最多一句话。

表头用：编号，类型，关键变量，该组作用。案件若有自己的分组因子，加一列即可。

对照句用下面这种，不要改成「配方是否有用」的叙述段：

```text
实施例1～n 对比 对比例a～b：证明……。
实施例1 对比 对比例c、d：证明……。
（实施例1－对比例c）与（对比例e－对比例f）：判断……。
实施例1 vs 对比例g：……。
```

中心组改编号时，对照句里的实施例号一起改。
